# 3.2 Wohin mit der Katze?

Akkusativ / Dativ · A2–B1 · afro-pop с танцем

**Сюжет:** Смешная история дома: куда бы я ни положила вещь, кошка уже там. Пары глаголов legen/liegen, stellen/stehen, hängen, setzen/sitzen.

**Ключевые примеры:** lege das Buch auf das Sofa → liegt auf dem Sofa · stelle die Vase ins Regal → steht im Regal · hänge die Jacke an die Tür → hängt an der Tür · setze sie auf das Bett → sitzt auf dem Bett

## Style
```
playful afrobeats pop, 108 bpm, bouncy bass, shakers and talking drum, funny storytelling, bright female vocal with spoken interjections, meow ad-libs, very clear German pronunciation
```
