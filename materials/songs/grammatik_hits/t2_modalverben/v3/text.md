# 2.3 Ich kann das

Модальные глаголы · A2 · техно-шлагер гимн

**Сюжет:** Год назад в пекарне смогла сказать только «Hallo», продавщица засмеялась. Сегодня заказывает булочки и сама всё объясняет врачу. Гимн тем, кто учит немецкий.

**Ключевые примеры:** konnte nur Hallo · wollte Brötchen kaufen · ich möchte lernen · kann bestellen · darf Fehler machen

## Style
```
uplifting techno schlager anthem, 130 bpm, euphoric piano chords over pounding kick, stadium chant, motivational, female lead with gang vocals, very clear and slow German pronunciation
```
