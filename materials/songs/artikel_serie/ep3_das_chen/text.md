# 3. Immer das! Teil 1 — Артикли по окончаниям

Для Suno: блок «Текст» в поле **Lyrics**, строку стиля в поле **Style**.

**Style:**
`german educational chant, rhythmic spoken-sung male baritone vocal, chill lo-fi pop beat, soft piano and light percussion, call and response, slow and very clear German pronunciation, short pause after each word, 88 bpm`

## Текст

```
[Intro]
Der, die, das — wer weiß das?
Hör aufs Ende, dann weißt du das!

[Verse 1]
Endet ein Wort auf „chen“ oder „lein“?
Immer das!
das Mädchen, das Brötchen, das Märchen,
das Kätzchen, das Büchlein, das Vöglein.
„chen“ oder „lein“ — immer das!

[Verse 2]
Endet ein Wort auf „um“?
Fast immer das!
das Museum, das Zentrum, das Datum,
das Studium, das Gymnasium, das Publikum.
„um“ — fast immer das!

[Verse 3]
Endet ein Wort auf „ment“?
Fast immer das!
das Instrument, das Dokument, das Experiment,
das Apartment, das Medikament, das Parlament.
„ment“ — fast immer das!

[Verse 4]
Endet ein Wort auf „ma“?
Fast immer das!
das Thema, das Klima, das Drama,
das Komma, das Schema, das Dilemma.
„ma“ — fast immer das!

[Verse 5]
Endet ein Wort auf „o“?
Fast immer das!
das Auto, das Kino, das Büro,
das Radio, das Foto, das Konto.
„o“ — fast immer das!

[Outro]
Chen und lein, um und ment, ma und o — immer das!
Der, die, das — jetzt weißt du das!
```

Исключения (только на экране, не поются): der Moment, der Konsum, die Firma, die Oma, der Euro, die Disco
