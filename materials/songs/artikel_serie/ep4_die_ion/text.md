# 4. Immer die! Teil 2 — Артикли по окончаниям

Для Suno: блок «Текст» в поле **Lyrics**, строку стиля в поле **Style**.

**Style:**
`german educational chant, rhythmic spoken-sung male baritone vocal, chill lo-fi pop beat, soft piano and light percussion, call and response, slow and very clear German pronunciation, short pause after each word, 88 bpm`

## Текст

```
[Intro]
Der, die, das — wer weiß das?
Hör aufs Ende, dann weißt du das!

[Verse 1]
Endet ein Wort auf „ion“?
Immer die!
die Information, die Situation, die Region,
die Lektion, die Station, die Religion.
„ion“ — immer die!

[Verse 2]
Endet ein Wort auf „tät“?
Immer die!
die Universität, die Qualität, die Realität,
die Kreativität, die Nationalität, die Spezialität.
„tät“ — immer die!

[Verse 3]
Endet ein Wort auf „ik“?
Fast immer die!
die Musik, die Politik, die Physik,
die Grammatik, die Fabrik, die Klinik.
„ik“ — fast immer die!

[Verse 4]
Endet ein Wort auf „ie“, wie Energie?
Immer die!
die Familie, die Energie, die Fantasie,
die Biologie, die Therapie, die Industrie.
„ie“ — immer die!

[Verse 5]
Endet ein Wort auf „ei“?
Fast immer die!
die Polizei, die Bäckerei, die Bücherei,
die Partei, die Türkei, die Metzgerei.
„ei“ — fast immer die!

[Outro]
Ion, tät, ik, ie und ei — immer die!
Der, die, das — jetzt weißt du das!
```

Исключения (только на экране, не поются): der Atlantik, das Genie, das Ei, der Papagei
