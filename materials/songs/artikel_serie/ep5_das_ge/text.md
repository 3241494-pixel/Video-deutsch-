# 5. Immer das! Teil 2 — Артикли по окончаниям

Для Suno: блок «Текст» в поле **Lyrics**, строку стиля в поле **Style**.

**Style:**
`german educational chant, rhythmic spoken-sung male baritone vocal, chill lo-fi pop beat, soft piano and light percussion, call and response, slow and very clear German pronunciation, short pause after each word, 88 bpm`

## Текст

```
[Intro]
Der, die, das — wer weiß das?
Hör aufs Ende, dann weißt du das!

[Verse 1]
Beginnt ein Wort mit „Ge“?
Meistens das!
das Gebäude, das Gemüse, das Getränk,
das Geschenk, das Gesicht, das Gespräch.
„Ge“ — meistens das!

[Verse 2]
Endet ein Wort auf „nis“?
Fast immer das!
das Ergebnis, das Zeugnis, das Erlebnis,
das Geheimnis, das Ereignis, das Hindernis.
„nis“ — fast immer das!

[Verse 3]
Endet ein Wort auf „tum“?
Meistens das!
das Eigentum, das Wachstum, das Christentum,
das Altertum, das Heiligtum, das Königtum.
„tum“ — meistens das!

[Verse 4]
Endet ein Wort auf „ett“?
Immer das!
das Bett, das Ballett, das Etikett,
das Tablett, das Skelett, das Kabinett.
„ett“ — immer das!

[Verse 5]
Wird ein Verb zum Nomen?
Immer das!
das Essen, das Leben, das Lernen,
das Schwimmen, das Treffen, das Wissen.
Verb als Nomen — immer das!

[Outro]
Ge und nis, tum und ett, Verb als Nomen — immer das!
Der, die, das — jetzt weißt du das!
```

Исключения (только на экране, не поются): der Geschmack, der Gedanke, die Geduld, die Erlaubnis, der Irrtum, der Reichtum
