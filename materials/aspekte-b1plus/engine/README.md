# Генератор грамматических роликов (серия Aspekte neu B1+)

Ролик описывается файлом-спецификацией (`v1_perfekt.py` и т.п.): блоки (заголовок, правила со строками-примерами, тест), фразы озвучки и привязка появления элементов к фразам/словам.
Шаги: скопировать папку в /home/user/gv (вне сетевого диска), затем
```
python engine.py v1_perfekt      # Piper TTS по фразам с паузами -> faster-whisper -> proj/index.html
./render.sh v1_perfekt           # пересобирает html, рендер HyperFrames, сведение с музыкой (bgm_long.wav из first-video), -14 LUFS
```
Темп: speed 0.85, 0.75 с между фразами, 1.8 с между блоками, 5 с таймер в тесте.
Музыка: из первого ролика (MusicGen, CC-BY-NC, только некоммерческое использование); `bgm_long.wav` = `../../first-video/audio/bgm.wav`, зацикленный с кроссфейдом.

## Видео 6–10 (20.10.2026)
Спецификации `v6_praepositionen.py` … `v10_adjektiv_ein.py`, они же сценарии. По просьбе Roman темп медленнее: в спецификации `SPEED, GAP_SEG, GAP_BLOCK, TIMER = 0.75, 0.9, 2.0, 8`; тест из двух частей по 6 фраз, таймер стоит в зоне субтитров.
Новое в движке: `"cls": "qa"` (вопрос и ответ в две строки), блок `"table"` (таблица падежей), «…» в фразе = настоящая пауза 0,6 с, промежуточный тест уходит со сцены.
Для страницы-артефакта ролики пережимаются до ~10 МБ (лимит 16 МБ на файл): `ffmpeg -i X.mp4 -c:v libx264 -preset slow -crf 28 -tune animation -c:a aac -b:a 128k -movflags +faststart`. В папках v6…v10 лежат исходники в полном качестве.
