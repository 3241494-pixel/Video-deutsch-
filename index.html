Сохранение отметок в GitHub

Отметки «опубликовано» хранятся в файле data/published.json этого репозитория. Чтобы ставить их отсюда, нужен личный токен GitHub. Он хранится только в этом браузере.

  1. Открой создание токена (fine-grained).
  2. Repository access: Only select repositories → Video-deutsch-.
  3. Permissions → Repository → Contents: Read and write. Создай токен и вставь сюда.
